# Chroma AI Worker

Десктопное приложение для помощи дальтоникам: в реальном времени распознаёт цвет светофора и отсылает результат в UI.

## Установка

### Вариант 1: Скачать готовый установщик

Скачайте установщик из релизов:

**[📥 Скачать v2.0.0](https://github.com/IDobrinya/Chroma-Worker/releases/tag/v2.0.0)**

### Вариант 2: Запуск из исходного кода

1. Убедитесь, что у вас установлен Python 3.8+ и Poetry
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/IDobrinya/Chroma-Worker.git
   cd Chroma-Worker
   ```
3. Установите зависимости:
   ```bash
   poetry lock
   poetry install
   ```
4. Запустите приложение:
   ```bash
   poetry run python -m chroma_ai
   ```

## Использование

1. Запустите приложение
2. Откройте веб-интерфейс: **https://chroma-ai-weld.vercel.app/**
3. Отсканируйте QR-код с помощью мобильного устройства или введите токен вручную
4. Результаты будут отображаться в веб-интерфейсе
